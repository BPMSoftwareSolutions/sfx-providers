A capability deck generated by `capability-deck.mjs` from declared reads, committed with its
read provenance. The subject is the DSL-authored read capability `read-capability-dsl-source`
(the first capability whose DSL source is retained at authoring time and returned byte-exact
through `read-capability-dsl-source` itself).

## Determinism

The generator is deterministic over a retained snapshot: regenerating from the committed
`snapshot.json` reproduces the identical content digest.

```powershell
node capability-deck.mjs --snapshot examples/capability-presentation/dsl-authoring-source-deck-20261015/snapshot.json `
  --dsl-source examples/capability-presentation/dsl-authoring-source-deck-20261015/declared-read.json `
  --dsl-source-run 2aa63f5e-424b-40ea-bfc9-5ba798e29e81 --output <new-directory>
# -> contentDigest 8ab18b22b253f6032baf642c2ba9975f6b0694db13090614ac3f1a40a228ad5d
```

The live estate read captures a fresh `capturedUtc` timestamp per run, so decks regenerated
directly from the estate carry the read's own testimony time; the retained snapshot replays
byte-stable.

## Regenerate from the live estate

```powershell
node capability-deck.mjs --capability-id read-capability-dsl-source `
  --dsl-source <read-capability-dsl-source result.json> --dsl-source-run <api-run-id> `
  --output <new-directory> --pptx
```

`presentation.pptx` is the transportable form (Google Slides batch requests per volume are in
`volume-*/google-batch.json`).
